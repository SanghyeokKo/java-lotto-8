# java-lotto-precourse
# 로또
## 기능요구사항
1. 랜덤 로또 번호 발행 기능
    - 로또 번호의 숫자 범위는 1~45까지
    - 1개의 로또를 발행할 때 중복되지 않는 숫자 6개를 뽑는다
2. 로또 번호 일치 검증 기능
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
3. 로또 번호 오름차순 정렬 기능
    - 랜덤으로 발행된 6개의 숫자를 오름차순으로 정렬
4. 수익률 계산 기능
    - 당첨 금액의 합 / 구입 금액 * 100
5. 입력 기능
    - 구입 금액 입력 기능
    - 당첨 번호 입력 기능(쉼표(,)를 기준으로 구분)
    - 보너스 번호 입력 기능
5. 출력 기능
    - 발행한 로또 수량 및 번호 출력 기능
    - 당첨 내역 출력 기능
    - 수익률 출력 기능
6. 검증 기능
    - 발행한 로또 번호 숫자가 1~45인지
    - 발행한 로또 번호의 숫자가 중복되지 않는지
    - 입력받은 구입 금액이 1,000원 단위로 나누어 떨어지는지
